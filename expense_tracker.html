☁️ Cloud Sync

📱 How to Use on Phone:
  1. Save this URL: Bookmark this page on all your devices
  2. Local Storage: Data syncs within your browser on each device
  3. Export & Import: Use Export/Import to sync between devices
  4. Cloud Drive: Store exports in Google Drive / Dropbox to share

📥 Export & Import

🔄 Sync Instructions

Laptop → Phone:
  1. Click "Export Data" on laptop
  2. Upload file to Google Drive / Dropbox
  3. Open this page on phone
  4. Click "Import Data" and select the file
  5. ✓ All data now on phone!
Phone → Laptop:
  1. Click "Export Data" on phone
  2. Share file to Google Drive
  3. Open this page on laptop
  4. Click "Import Data" and select the file
  5. ✓ All data now on laptop!

💡 Pro Tips

  • Weekly backups: Export every Sunday to cloud storage
  • Always backup first: Before making major changes, export
  • Multiple devices: Keep all devices up to date by importing latest exports
  • Share with family: Export and share encrypted file via email
